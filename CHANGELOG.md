# Changelog

## 0.1.1 (29 September 2026)

The first version on Maven Central. The code is the same as 0.1.0.

- Add `implementation("lk.payments:payments-lk-android:0.1.1")`; no local Maven repository or source module is needed. The artefacts are signed and carry the sources.
